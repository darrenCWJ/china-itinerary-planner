# Prototypes

One-off research artifacts from before the app existed, kept because the specs
cite them as provenance rather than because anything runs them.

- `interactive_trip_planner.html` — the Fujian–Kinmen multi-generational tour
  planner that prompted the trip-briefing feature
  (`docs/superpowers/specs/2026-08-12-trip-briefing-design.md`).
- `family_trip_presentation_deck.html` — the accompanying presentation deck.

Both are standalone pages built against CDN Tailwind, Chart.js and Plotly. They
are **not** part of the build, are not linked from the app, and are not
maintained. Nothing here should be treated as current: where a prototype and the
shipped app disagree, the app is right.
